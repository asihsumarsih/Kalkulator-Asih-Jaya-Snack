# Kalkulator Android (Tombol 0, 00, 000)

Proyek ini otomatis membangun file **APK Android** menggunakan **GitHub Actions** dan **Capacitor**.

## Cara Mendapatkan File APK di GitHub:
1. Buat repositori baru di GitHub.
2. Ekstrak semua isi file ZIP ini dan unggah seluruh isi foldernya ke repositori GitHub Anda (pastikan folder `.github` ikut terunggah).
3. Buka tab **Actions** di repositori GitHub Anda.
4. Tunggu proses **Build Android APK** selesai (sekitar 2–4 menit hingga muncul centang hijau).
5. Klik hasil build tersebut, gulir ke bawah ke bagian **Artifacts**, dan unduh **Kalkulator-APK**.
